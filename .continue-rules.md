\# Vibe Coding AI Project Rules



\## General



\- Inspect the repository before making changes.

\- Keep changes small and reversible.

\- Prefer existing dependencies over adding new ones.

\- Never hard-code API keys or credentials.

\- Use environment variables for external services.



\## Python



\- Use Python 3.12-compatible code.

\- Use type hints where practical.

\- Keep business logic separate from API routes.

\- Use pytest for tests.

\- Use Ruff for linting.



\## AI Architecture



The project is designed around:



User

&#x20;   ↓

API Gateway

&#x20;   ↓

Task Classifier

&#x20;   ↓

Model Router

&#x20;   ↓

Provider

&#x20;   ↓

Cloud GPU / Ollama



The provider layer must remain independent from

specific model implementations.



\## Models



Current logical roles:



\- Coding:

&#x20; DeepSeek Coder



\- Reasoning:

&#x20; Qwen3 Thinking



\- Vision:

&#x20; Devstral/mmproj-based vision pipeline



Model execution is disabled during local setup.



\## Cloud Migration



The application must be able to move from:



Local development

&#x20;       ↓

Cloud GPU

&#x20;       ↓

Ollama / model server



without rewriting routing logic.
