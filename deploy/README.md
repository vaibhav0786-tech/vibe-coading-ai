# Cloud Deployment

This directory contains deployment configuration for the Vibe Coding AI system.

Local laptop:
- Development
- Configuration
- Code editing
- Automated checks

Cloud GPU:
- Ollama
- GGUF models
- OpenWebUI
- Vibe Coding AI gateway
- Aider/Continue connections

No model inference is required on the laptop.

## Planned cloud services

- Ollama: 11434
- Vibe Coding Gateway: 8000
- OpenWebUI: 3000

## Security

Do not expose Ollama or the gateway directly to the public internet without authentication,
firewall rules, or a private network/VPN.
